## 👨‍💻 Sobre mim

Construo **APIs REST seguras, escaláveis e bem estruturadas** com Java e Spring Boot.

Nos meus projetos implementei autenticação **JWT com refresh token**, **two-factor authentication (TOTP)**, **login social com OAuth2** (Google e GitHub), **arquitetura de microsserviços** com Spring Cloud (Eureka, Gateway, OpenFeign) e **comunicação assíncrona orientada a eventos** com Apache Kafka.

Sou formado em **Análise e Desenvolvimento de Sistemas** e atuo hoje com suporte e infraestrutura de TI no Grupo Roveri — experiência que me deu base sólida em ambientes corporativos, redes e resolução de problemas. Direciono minha carreira para **desenvolvimento back-end**.

**Áreas de maior interesse:** segurança de aplicações, arquitetura de sistemas distribuídos e boas práticas de API design.
